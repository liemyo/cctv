Kebijakan Privasi Pantau CCTV

Berlaku untuk situs liemyo.github.io/cctv dan aplikasi Pantau di Mac. Diperbarui 2 November 2026.

Data yang dipakai

  • Akun iCSee / XMeye Anda dipakai langsung dari browser ke server iCSee untuk menampilkan kamera. Kata sandi tidak dikirim ke server kami.
  • Klip Gerak (foto dan video saat ada gerakan) disimpan privat di cloud Pantau (Supabase), hanya bisa dibuka dengan kunci cloud milik Anda.

Google Drive

  • Bila Anda menyambungkan Google Drive, Pantau meminta izin drive.file: hanya file yang dibuat Pantau sendiri (folder "Pantau Klip"). Pantau tidak bisa melihat file Drive Anda yang lain.
  • Pantau juga membaca alamat email akun Google untuk ditampilkan sebagai akun yang tersambung.
  • Token Google disimpan terenkripsi di server Pantau dan hanya dipakai untuk mengunggah, memutar, dan menghapus video klip di folder tersebut. Data tidak dijual atau dibagikan ke pihak lain.
  • Putuskan kapan saja di menu Saya › Klip Gerak, atau di myaccount.google.com/permissions.
