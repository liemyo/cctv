# Pantau CCTV (web)

Versi web aplikasi Pantau — buka kamera iCSee / XMeye dari browser dengan akun yang sama.
Langsung ke cloud iCSee (rs.xmeye.net, api.jftechws.com), tanpa server perantara.

Live Cepat = FLV H.265 asli kamera via mpegts.js (butuh browser yang bisa HEVC), cadangan HLS H.264.
Klip Gerak dibaca dari Supabase yang diisi aplikasi Pantau di Mac (pakai kunci cloud dari Saya › Cloud).
